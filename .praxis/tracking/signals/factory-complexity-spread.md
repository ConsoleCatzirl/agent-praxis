# Signal: Complexity Spread

## Description

How the complexity levels of the factory are distributed: Patterns, scripts, and skills by level (Trivial, Regex, Mechanical, Structural, Qualitative) at the end of each run.

## Metric

Per run, the count of Patterns, scripts and skills at each level, from the `Complexity:` of each product's file, in the tree of the run's `Clear state` commit.

## Purpose

As steps move to lower complexity levels in scripts and skills, the spread should widen; if everything stays Qualitative, the levels do not discriminate and the rule that a Plan takes the highest level of its skills needs another look.

## Notes

No values yet; `praxis-flow-learn` writes the first value under a Values heading when a run is recorded.
