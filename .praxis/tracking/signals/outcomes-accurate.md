# Signal: Accurate Outcomes

## Description

The share of Analyses whose Result is Accurate: all expected outcomes occurred and no unexpected outcome occurred.

## Metric

Accurate Analyses divided by all non-Bypassed Analyses, per run and across recorded runs.

## Purpose

Tracks how well Predictions match what happens, one of the two measures of calibration (with Surprise Rate), and so how far Predictions can be trusted at Discern.

## Notes

No values yet; `praxis-flow-learn` writes the first value under a Values heading when a run is recorded.
