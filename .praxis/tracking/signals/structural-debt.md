# Signal: Structural Debt

## Description

The findings the structural checks report on the tree: how far the records are from their templates and lifecycles.

## Metric

The sum of the finding counts of the structural checks (cohesion, templates, statuses, lifecycles, locations, references, terms, complexity, alignment) on the current tree, with each count, taken at Learn. A change to a check changes what it counts; a value is comparable only with the same check versions.

## Purpose

Shows whether runs pay the debt down or add to it, and which kind (references, retired terms, templates) dominates. It also shows when the checks disagree.

## Notes

No values yet; `praxis-flow-learn` writes the first value under a Values heading when a run is recorded.
