# Signal: Recurring Misalignment

## Description

Domain items that appear repeatedly as not followed: named in an Analysis's Domain Misalignment, or listed Ambiguous or Contradictory in another item's Domain Alignment.

## Metric

For each domain item, the number of independent recorded runs whose Analysis named it in Domain Misalignment, plus the number of items that list it as Ambiguous or Contradictory. An item named in two or more runs is recurring.

## Purpose

Finds items that are repeatedly set aside, are in conflict with each other, or no longer fit the work: candidates for refinement, a synthesis, or a lifecycle move.

## Notes

No values yet; `praxis-flow-learn` writes the first value under a Values heading when a run is recorded.
