# Signal: Helpful Outcomes

## Description

The share of Analyses whose Result is Helpful: all expected outcomes occurred and beneficial unexpected outcomes occurred as well.

## Metric

Helpful Analyses divided by all non-Bypassed Analyses, per run and across recorded runs.

## Purpose

Shows how often work does better than predicted, which is evidence that Predictions are under-ambitious or that unplanned benefits are being found.

## Notes

No values yet; `praxis-flow-learn` writes the first value under a Values heading when a run is recorded.
