# Praxis Decompose

Decompose the user prompt into a list of Tasks.

## Origin
Initial Implementation

## Purpose

Create Tasks based on the user prompt.

## When to Use

When a user submits a prompt, before any action is taken.

## How it Works

## Requirements

Coherent user prompt

## Input

Coherent user prompt

## Procedure

1. Review the types of Tasks
2. Identify all Tasks contained in the user prompt
3. Ask the user for any needed clarity
4. Write Tasks to state
5. Continue to the Praxis Plan stage with these Tasks

## Output

One or more Defined Tasks

## Success Criteria

All Tasks inferred from the user prompt are written to state.
