# Skill: Praxis Act

Perform an approved Plan and record the Outcome 

## Origin
Initial Implementation

## Purpose
Actualize the Plan

## When to Use
When a Plan and its Prediction are Approved, before the Reflect phase

## How it Works

## Requirements

Approved Plan and related Prediction

## Inputs

Approved Plan and related Prediction

## Procedure

For each Plan, perform the Plan's procedure and record all Outcomes using `.praxis/templates/outcomes-template.md`
As each Plan completes execution, mark it and its associated Tasks as Completed and its Prediction as Actualized.

## Output

An Outcome for each Plan actualized.

## Success Criteria

An Outcome is documented for each Plan, and all Tasks are Completed
