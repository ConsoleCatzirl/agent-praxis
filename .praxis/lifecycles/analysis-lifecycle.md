# Analysis Lifecycle

Analyses are created, processed, and then cleared.

## Stages

- Created
- Processed

## Stage Flow

Created -> Processed

## Stage 1: Created

An analysis has been recorded

**Entry Paths:**
- New analysis is written to file

**Exit Paths:**
Processed:
- Domains and tracking have been updated based on this analysis

## Stage 2: Processed

Analysis updates have been applied

**Entry Paths:**
- Domains and tracking have been updated based on this analysis
