# Skill: Praxis Learn

Review the results of the analysis for appropriate changes in tracking or domains.

## Origin
Praxis Template

## Purpose
Review Outcome Analyses to update Tracking, Guiding, and Steering appropriately

## When to Use
After Outcomes have been analyzed, before recording and reporting on this Flow iteration.

## How it Works

## Requirements

Analyzed Outcomes for all Approved Plans.

## Inputs

Completed Analyses

## Procedure

1. Once all Approved or Bypassed Plans have Created or Bypassed Analyses:
  1. Review each Plan, Prediction, Outcome, and Analysis for:
    - Semantic and epistemic consistency across domain items, highlighting contradictions and ambiguity.
    - Identifying new factory products.
    - Identifying changes to domain items.
  2. Summarize the review.
2. Review the overall quality of this iteration of the flow.
3. Apply changes to confidence tables and Signals.
4. Prompt the user with any proposed domain item or factory product changes.

## Output

Potential updates across `.praxis/`.

## Success Criteria
Analyses for this iteration have been processed for praxis updates.
