# Skill: Praxis Predict

Predict anticipated outcomes for the current Plan

## Origin
Praxis Template

## Purpose

Predict anticipated outcomes for the current Plan

## When to Use

After creating Plans, before discerning Plan approval

## How it Works

## Requirements

One or more Created Plans in `.praxis/state/plans.md`.

## Inputs

One or more Created Plans

## Procedure

As each Plan is created or revised:
1. Assess the Plan's procedure and list the expected outcomes and side-effects.
2. Create the Prediction in `.praxis/state/predictions`.

## Output

A Prediction in `.praxis/state/predictions.md` for each Plan in `.praxis/state/plans.md`.

## Success Criteria

All Plans have Predictions
