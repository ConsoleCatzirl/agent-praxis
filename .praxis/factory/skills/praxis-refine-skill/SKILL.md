# Skill: Praxis Refine Skill

The process for modifying skills. 

## Origin
Praxis Template

## Purpose
Iterative improvement.

## When to Use
When modifying the behavior of a skill.

## How it Works

## Requirements
An existing skill and a reason to modify it.

## Inputs
Factory products and domain items.

## Procedure

1. Read the following files if they are not already in context:
  - `.praxis/{domains,factory}/*md`
  - `.praxis/templates/skill-template.md`
2. If an existing factory product exists to address the purpose of the change, incorporate it into the skill.
3. Add any additional procedure steps that may be required to fulfill the purpose of the change.
4. If an existing factory product needs to be modified, create a Task and Plan for that modification.
5. 

## Output

A modified skill with adjusted confidence.

## Success Criteria

Either a new skill, tool, or script  under `.praxis/factory/`, or a new Pattern in `.praxis/factory/patterns/`
