# Patterns

## Pattern Lifecycle

Patterns follow the evidence-based lifecycle defined at `.praxis/lifecycles/evidenced-lifecycle.md`.

## Pattern Template

Each pattern is created at `.praxis/factory/patterns/${item-name}.md` from `.praxis/templates/pattern-template.md`.

## List of Patterns

A list of patterns can be found at `.praxis/factory/patterns.md`, with links to more information for each at `.praxis/factory/patterns/${item-name}.md`.
