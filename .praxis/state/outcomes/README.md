# Plan Outcomes

## Outcome Lifecycle

Outcomes follow their own lifecycle defined at `.praxis/lifecycles/outcome-lifecycle.md`.

## Outcome Template

Each outcome for each plan is created at `.praxis/state/outcomes/${plan-name}.md` from `.praxis/templates/outcome-template.md`.

## List of Outcomes

A list of outcomes can be found at `.praxis/state/outcomes.md`, with links to more information for each at `.praxis/state/outcomes/${plan-name}.md`.
