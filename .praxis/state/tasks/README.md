# Tasks of Plan Outcomes

## Task Lifecycle

Tasks follow their own lifecycle defined at `.praxis/lifecycles/task-lifecycle.md`.

## Task Template

Each task for each plan is created at `.praxis/state/tasks/${task-name}.md` from `.praxis/templates/task-template.md`.

## List of Tasks

A list of tasks can be found at `.praxis/state/tasks.md`, with links to more information for each at `.praxis/state/tasks/${plan-name}.md`.

## Task Types

This is an incomplete list of task categories:

- Imperative instruction
- Information synthesis
- Interact with external systems
- Mutate state
- Other forms of requests or demands
