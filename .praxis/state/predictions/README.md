# Predictions of Plan Outcomes

## Prediction Lifecycle

Predictions follow their own lifecycle defined at `.praxis/lifecycles/prediction-lifecycle.md`.

## Prediction Template

Each prediction for each plan is created at `.praxis/state/predictions/${plan-name}.md` from `.praxis/templates/prediction-template.md`.

## List of Predictions

A list of predictions can be found at `.praxis/state/predictions.md`, with links to more information for each at `.praxis/state/predictions/${plan-name}.md`.
