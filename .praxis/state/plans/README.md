# Plans for Tasks

## Plan Lifecycle

Plans follow their own lifecycle defined at `.praxis/lifecycles/plan-lifecycle.md`.

## Plan Template

Each plan for each plan is created at `.praxis/state/plans/${plan-name}.md` from `.praxis/templates/plan-template.md`.

## List of Plans

A list of plans can be found at `.praxis/state/plans.md`, with links to more information for each at `.praxis/state/plans/${plan-name}.md`.
