# Analyses of Plan Outcomes

## Analysis Lifecycle

Analyses follow their own lifecycle defined at `.praxis/lifecycles/analysis-lifecycle.md`.

## Analysis Template

Each analysis for each plan is created at `.praxis/state/analyses/${plan-name}.md` from `.praxis/templates/analysis-template.md`.

## List of Analyses

A list of analyses can be found at `.praxis/state/analyses.md`, with links to more information for each at `.praxis/state/analyses/${plan-name}.md`.
