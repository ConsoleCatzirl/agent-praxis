# Intentions

## Intention Lifecycle

Intentions follow the assertion-based lifecycle defined at `.praxis/lifecycles/assertion-lifecycle.md`.

## Intention Template

Each intention is created at `.praxis/domains/intentions/${item-name}.md` from `.praxis/templates/intention-template.md`.

An intention's name is a gerund phrase, an aim that goes on and is not a command ("Improving With Each Run"). The name states a direction that is never finished, not a deliverable. Items that express one idea at a different commitment share a stem (`.praxis/domains/README.md`, "Naming").

## List of Intentions

A list of intentions can be found at `.praxis/domains/intentions.md`, with links to more information for each at `.praxis/domains/intentions/${item-name}.md`.
