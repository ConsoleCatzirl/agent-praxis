# Principles

## Principle Lifecycle

Principles follow the assertion-based lifecycle defined at `.praxis/lifecycles/assertion-lifecycle.md`.

## Principle Template

Each principle is created at `.praxis/domains/principles/${item-name}.md` from `.praxis/templates/principle-template.md`.

A principle's name is a noun phrase headed by a nominalization, a doctrine and not a command ("Anticipation Before Action"). The name states the reason that practices and rules follow from. Items that express one idea at a different commitment share a stem (`.praxis/domains/README.md`, "Naming").

## List of Principles

A list of principles can be found at `.praxis/domains/principles.md`, with links to more information for each at `.praxis/domains/principles/${item-name}.md`.
