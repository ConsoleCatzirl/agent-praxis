# Opinions

## Opinion Lifecycle

Opinions follow the assertion-based lifecycle defined at `.praxis/lifecycles/assertion-lifecycle.md`.

## Opinion Template

Each opinion is created at `.praxis/domains/opinions/${item-name}.md` from `.praxis/templates/opinion-template.md`.

An opinion's name is an evaluative or comparative clause that states no obligation ("Automating a Task Beats Performing It"). The comparison is explicit and subjective. Items that express one idea at a different commitment share a stem (`.praxis/domains/README.md`, "Naming").

## List of Opinions

A list of opinions can be found at `.praxis/domains/opinions.md`, with links to more information for each at `.praxis/domains/opinions/${item-name}.md`.
