# Practices

## Practice Lifecycle

Practices follow the assertion-based lifecycle defined at `.praxis/lifecycles/assertion-lifecycle.md`.

## Practice Template

Each practice is created at `.praxis/domains/practices/${item-name}.md` from `.praxis/templates/practice-template.md`.

## List of Practices

A list of practices can be found at `.praxis/domains/practices.md`, with links to more information for each at `.praxis/domains/practices/${item-name}.md`.
