# Beliefs

## Belief Lifecycle

Beliefs follow the evidence-based lifecycle defined at `.praxis/lifecycles/evidenced-lifecycle.md`.

## Belief Template

Each belief is created at `.praxis/domains/beliefs/${item-name}.md` from `.praxis/templates/belief-template.md`.

## List of Beliefs

A list of beliefs can be found at `.praxis/domains/beliefs.md`, with links to more information for each at `.praxis/domains/beliefs/${item-name}.md`.
