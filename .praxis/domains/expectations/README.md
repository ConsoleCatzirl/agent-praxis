# Expectations

## Expectation Lifecycle

Expectations follow the evidence-based lifecycle defined at `.praxis/lifecycles/evidenced-lifecycle.md`.

## Expectation Template

Each expectation is created at `.praxis/domains/expectations/${item-name}.md` from `.praxis/templates/expectation-template.md`.

An expectation's name is a clause with a futurate or tendency verb (will, tends to, usually) so that it is not read as a belief ("A Compaction Will Drop the Templates the Skills Load"). The name states a cause and an effect. Items that express one idea at a different commitment share a stem (`.praxis/domains/README.md`, "Naming").

## List of Expectations

A list of expectations can be found at `.praxis/domains/expectations.md`, with links to more information for each at `.praxis/domains/expectations/${item-name}.md`.
