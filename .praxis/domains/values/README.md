# Values

## Value Lifecycle

Values follow the assertion-based lifecycle defined at `.praxis/lifecycles/assertion-lifecycle.md`.

## Value Template

Each value is created at `.praxis/domains/values/${item-name}.md` from `.praxis/templates/value-template.md`.

## List of Values

A list of values can be found at `.praxis/domains/values.md`, with links to more information for each at `.praxis/domains/values/${item-name}.md`.
